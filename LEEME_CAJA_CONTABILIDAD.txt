MORDISCO — REPARAR CAJA Y CONTABILIDAD

CORRIGE
1. CONTABILIDAD
- Cada tarjeta abre únicamente su módulo.
- El módulo se muestra en una ventana flotante.
- Se cierra con X, tocando fuera o con Escape.
- Al cerrar vuelve a quedar oculto.

2. CAJA
- Los pedidos pendientes vuelven a mostrar:
  Editar, Cobrar y Cancelar.
- El render funciona aunque falte información de mesa o productos.
- Los botones siempre quedan visibles.
- Cobrar abre la ventana de cobro normal.

NO CAMBIA
- Pedidos web
- WhatsApp
- Club Mordisco
- Supabase
- Ventas guardadas
- Cocina
- Turnos

INSTALACIÓN
1. Extrae el ZIP.
2. Copia todo dentro de:
   C:\Users\USER\Documents\GitHub\mordisco-os-v20
3. Reemplaza archivos.
4. GitHub Desktop:
   Summary: Reparar Caja y ventanas de Contabilidad
5. Commit to main.
6. Push origin.
7. Espera Vercel Ready.
8. Abre:
   https://mordiscofastfood.com/admin?v=cash-finance-fixed-2
9. Presiona Ctrl + Shift + R.

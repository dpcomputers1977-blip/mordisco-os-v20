MORDISCO — COCINA AUTOMÁTICA, PRODUCTOS Y SONIDO

CORRIGE
- Consulta pedidos automáticamente cada 4 segundos.
- Funciona aunque Supabase Realtime no avise.
- Muestra productos, cantidades y notas.
- Emite tres tonos y vibración cuando llega un pedido nuevo.
- Actualiza al regresar a la aplicación o desbloquear el teléfono.

IMPORTANTE PARA EL SONIDO
- En Cocina, toca una vez la casilla Sonido.
- Debe escucharse un tono de prueba.
- Deja marcada la casilla.
- Verifica que el teléfono no esté en silencio.

PUBLICAR
1. Extrae este ZIP.
2. Copia todo dentro de:
   C:\Users\USER\Documents\GitHub\mordisco-os-v20
3. Reemplaza archivos.
4. GitHub Desktop:
   Summary: Cocina automática con productos y sonido
5. Commit to main.
6. Push origin.
7. Espera Vercel Ready.

SUPABASE
1. Abre SQL Editor.
2. Ejecuta UNA SOLA VEZ:
   13_COCINA_AUTO_PRODUCTOS_SONIDO.sql

PRUEBA
1. Cocina cierra sesión y entra desde:
   https://mordiscofastfood.com/staff?v=kitchen-auto-detail-sound
2. Toca Sonido una vez y escucha la prueba.
3. Crea un pedido nuevo desde Caja.
4. Debe aparecer en máximo 4 segundos con sus productos y sonido.

MORDISCO — TURNOS CONTROLADOS POR EL ADMINISTRADOR

NUEVO FLUJO
1. El administrador entra a Turnos.
2. Selecciona un empleado.
3. Escribe el efectivo inicial.
4. Pulsa Abrir turno.
5. El cajero ya puede cobrar.
6. Al terminar, selecciona al empleado, escribe el efectivo contado y pulsa Cerrar turno.

NO CAMBIA
- Productos
- Ventas realizadas
- Pedidos
- Empleados
- Permisos
- Página pública
- Inventario
- Contabilidad

PUBLICAR
1. Extrae este ZIP.
2. Copia todo dentro de:
   C:\Users\USER\Documents\GitHub\mordisco-os-v20
3. Reemplaza archivos.
4. GitHub Desktop:
   Summary: Administrador controla turnos
5. Commit to main.
6. Push origin.
7. Espera Vercel Ready.

SUPABASE
1. Abre SQL Editor.
2. Ejecuta una sola vez:
   09_ADMIN_ABRIR_CERRAR_TURNOS.sql

Después entra como administrador, abre Turnos y selecciona al cajero.
